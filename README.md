## 买完之后怎么用

流程不复杂，和你平时远程办公差不多：

1. 开通后商家会发 IP、用户名和密码，Windows、Mac、iPhone、iPad、Android 都有对应的远程桌面客户端；
2. 连上去之后是个正常的 Windows Server 2022 桌面，下载安装MT4或MT5、登录你的券商账户、挂上EA；
3. 断开远程桌面后程序**继续运行**——这是关键。但注意，如果你在 VPS 里登出 Windows 或者直接关机，EA 就停了。用完点“断开连接”就行，别手滑点了“关机”；
4. 之后想看账户，随时从任何设备重新连上去。

回测这种吃CPU的活儿，建议放在FOREX-3以上的配置跑，或者错开交易时段，免得影响挂单中的EA。

## FAQ

**FOREX-1 的 2GB 内存真的够吗？**
单个MT4/MT5终端加上几个常规EA，占用远低于 2GB。够不够的标准很简单：开完所有终端和EA后看任务管理器，内存占用长期低于 70% 就不用升级；经常贴着上限，就升 FOREX-2。

**流量不限是什么意思？**
指不设月度流量总额限制，但端口速度上限 1Gbps。跑MetaTrader的流量本来就很小，这条对你几乎没有约束。

**月付 $16，没有更便宜的年付价吗？**
官方 Forex VPS 页面目前只展示月付价格，没有公示年付折扣或续费价。结账页是否有其他周期可选，以下单时的实际展示为准，不要按任何第三方转述的“年付价”预算。

**怎么确认我的券商和它的节点匹配？**
先查券商官网或问客服你的账户服务器在哪个城市（纽约、伦敦是最常见的答案），再向 GreenCloud 客服确认 Forex VPS 是否有对应或就近的节点。他们的工单平均响应 9 分钟，问一句的成本很低。
